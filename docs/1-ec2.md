# Instancia de AWS EC2 y conexión através de SSH

Detalla el procedimiento paso a paso para crear, configurar y conectarse de forma segura a una instancia de servidor virutal como lo es Amazon EC2 utilizando Ubuntu Server


## Pre-requisitos
* Tener una cuenta activa en Amazon Web Services (AWS)
* 


## Lanzamiento de instancia
Desde la consola de gestión de AWS seguimos los siguientes pasos:

* Nombre de la instancia, en este proyecto fue: hostingudv. Se puede poner cualquier nombre relacionado al proyecto
* Se utilizó el AMI o Imagen del sistema: Ubuntu Server porque es estable, seguro y con soporte a largo plazo
* El tipo de instancia que utilizamos fue t3.micro que es el que AWS ofrece gratuitamente. Se tiene que considerar el tamaño del proyecto y requerimientos del mismo.
* Almacenamiento, el almacenamiento también varía dependiendo del proyecto.

## Claves SSH (Key Pair)

Cofiguramos la autenticación mediante pares de claves RSA.

1. En la sección **Key Pair (login)**, seleccionamos **Create new key pair**
2. **Nombre de par de claves** 'el-nombre-del-proyecto-key'
3. **Tipo de clave** 'RSA'
**Formato de archivo** '.pem'
Guardamos el archivo descargado en una carpeta segura.
Hay algo muy importante que hay que tomar en cuenta, este archivo contiene la llave privada y nunca hay que compartir dicha llave.


### Configuración del firewall en AWS
 * se creó un nuevo security group con nombre 'proyecto' para controlar el control de entrada y salida

SSH│ TCP │ 22│ My IP (<TU_IP_LOCAL>/32) │Administración remota segura
